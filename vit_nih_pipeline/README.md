# ViT NIH Chest X-ray Binary Classification Pipeline

Vision Transformer-based binary classification on the NIH Chest X-ray dataset (Infiltration vs No Finding).

## Project Structure

```
vit_nih_pipeline/
├── configs/
│   └── config.py          # All parameters centralized (most visible location)
├── src/
│   ├── __init__.py
│   ├── dataset.py         # Data loading, stratified split, DataLoader
│   ├── model.py           # ViT model (PatchEmbedding + Transformer + Head)
│   ├── train.py           # Training loop, validation, early stopping, checkpoint
│   ├── evaluate.py        # Test evaluation, confusion matrix, training curves
│   └── utils.py           # Image preprocessing, metric computation, checkpoint I/O
├── scripts/
│   ├── train.py           # Training entry point (CLI args supported)
│   └── evaluate.py        # Evaluation entry point
├── checkpoints/           # Model checkpoints
├── outputs/               # Visualization outputs
├── requirements.txt       # Dependencies
└── README.md              # Documentation
```

## Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure Kaggle API

Download [Kaggle API Token](https://www.kaggle.com/settings/account) and place it at `~/.kaggle/kaggle.json`:

```bash
mkdir -p ~/.kaggle
chmod 600 ~/.kaggle/kaggle.json
```

### 3. Train Model

```bash
# Basic training (default parameters)
python scripts/train.py

# Quick debug with subset (1000 train / 200 val)
python scripts/train.py --subset

# Custom parameters
python scripts/train.py     --img-size 64     --patch-size 16     --embed-dim 32     --num-heads 4     --transformer-units 1     --batch-size 64     --lr 0.01     --epochs 150

# Resume from checkpoint
python scripts/train.py --resume checkpoints/checkpoint_epoch_50.pth
```

### 4. Evaluate Model

```bash
python scripts/evaluate.py --checkpoint checkpoints/best_model.pth
```

## How to Change the Classification Task

The label encoding is now fully configurable via `configs/config.py` or command-line arguments. To switch to a different binary classification task (e.g., **Pneumonia vs No Finding**):

### Method 1: Edit `configs/config.py` (Recommended for permanent changes)

Open `configs/config.py` and modify the `DataConfig` class:

```python
@dataclass
class DataConfig:
    # Change target labels
    target_labels: Tuple[str, ...] = ("Pneumonia", "No Finding")

    # Define label mapping: text -> integer class index
    # 'No Finding' should be class 0 (negative), disease class 1 (positive)
    label_map: Dict[str, int] = None  # Auto-generated by default

    # Class names for reports and visualizations (auto-generated from label_map)
    class_names: Tuple[str, ...] = None  # Auto-generated by default
```

The `label_map` and `class_names` are **auto-generated** in `__post_init__` with the following logic:
- If `"No Finding"` is in `target_labels`, it is assigned class `0`
- The first disease label found is assigned class `1`
- `class_names` is sorted by `label_map` values to ensure report consistency

### Method 2: Command-Line Override (For quick experiments)

```bash
python scripts/train.py     --target-labels Pneumonia "No Finding"     --label-map '{"No Finding": 0, "Pneumonia": 1}'
```

**Note:** When using `--target-labels`, you must also provide `--label-map` as a JSON string, or let the script auto-generate it (if `"No Finding"` is included).

### Important Notes on Label Configuration

| Parameter | Description | Default |
|-----------|-------------|---------|
| `target_labels` | Tuple of two label strings from the NIH dataset | `("Infiltration", "No Finding")` |
| `label_map` | Dictionary mapping label text to integer class index | Auto-generated |
| `class_names` | Tuple of class names for reports/visualizations | Auto-generated from `label_map` |

**Rules:**
1. `label_map` values must be contiguous integers starting from `0` (e.g., `0, 1`)
2. `class_names` order must match `label_map` values (index `0` name first, index `1` name second)
3. The positive class (disease) should be index `1` for correct F1/Recall computation

## Core Parameters

All parameters are centralized in `configs/config.py`:

| Parameter | Description | Default |
|-----------|-------------|---------|
| `img_size` | Input image size | 64 |
| `patch_size` | Patch size (must divide img_size) | 16 |
| `embed_dim` | Patch embedding dimension | 32 |
| `num_heads` | Attention head count | 4 |
| `transformer_units` | Transformer layer count | 1 |
| `mlp_dim` | MLP hidden dimension | 64 |
| `batch_size` | Batch size | 64 |
| `lr` | Learning rate | 0.01 |
| `epochs` | Training epochs | 150 |

## Data Pipeline

1. **Download**: Auto-download via `kagglehub`
2. **Split**: Stratified split by `Patient ID` to prevent data leakage
3. **Filter**: Keep only images with labels in `target_labels`
4. **Preprocess**: Grayscale -> Resize -> Normalize -> (1, H, W)

## Model Architecture

```
Input (1, 64, 64)
  ↓
Patch Embedding (Conv2d: 1→32, kernel=16, stride=16)
  ↓
Add CLS Token + Positional Embedding
  ↓
Transformer Encoder x N
  - Multi-Head Self-Attention
  - Feed-Forward Network (GELU)
  - LayerNorm + Residual
  ↓
MLP Head (CLS Token -> 2 classes)
```
