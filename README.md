# ViT-ChestXray8-Classification
A repository for Novo Nordisk PBL course in BlendED AI+X program. We're team in track 1 from the session 2026.3.9-2026.5.14
📌 Project Overview
This project implements a Vision Transformer (ViT) model from scratch for multi-label classification on the NIH ChestX-ray8 dataset.
The goal is to explore how transformer-based architectures can be applied to medical imaging tasks.

🧠 Key Features
Patch-based image embedding
Multi-head self-attention mechanism
Multi-label classification
Stratified sampling for imbalanced medical data
Attention visualization

📂 Dataset
We use the NIH ChestX-ray8 dataset:
Grayscale chest X-ray images
Multi-label disease annotations
Highly imbalanced classes

⚙️ Data Processing
Multi-label encoding
Stratified train/val/test split
Image resizing and normalization

🏗 Model Architecture
Patch Embedding via Conv2D
Positional Encoding
Transformer Encoder
CLS Token for classification
